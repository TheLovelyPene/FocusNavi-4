# Demo Scenarios for Accessible Navigation

## 🎬 Demo Scripts for Testing

### Scenario 1: Daily Commute (Standalone App)
**Duration**: 3-5 minutes  
**Purpose**: Show real-world navigation with accessibility features

```
1. SETUP
   - Open standalone app
   - Show route setup screen

2. INPUT ADDRESSES
   Origin: "123 Main Street, San Francisco, CA"
   Destination: "456 Market Street, San Francisco, CA"
   
3. CONFIGURE PREFERENCES
   - Enable "Prefer accessible paths"
   - Enable "Avoid tolls"
   - Click "Start Navigation"

4. DEMONSTRATE FEATURES
   - Show route calculation with real Mapbox data
   - Click "Satellite" to show satellite imagery
   - Use voice command: "Hey Assistant, where am I?"
   - Advance through navigation steps
   - Show accessibility descriptions

5. HIGHLIGHT BENEFITS
   - Point out detailed path descriptions
   - Show lane guidance for accessibility
   - Demonstrate large text and clear interface
```

### Scenario 2: Google Maps Enhancement (Extension)
**Duration**: 2-3 minutes  
**Purpose**: Show how extension enhances existing Google Maps

```
1. SETUP
   - Open Google Maps in Chrome
   - Show normal Google Maps interface
   - Point out extension icon in toolbar

2. ACTIVATE EXTENSION
   - Click extension icon to show popup
   - Point out accessibility panel on page
   - Show available features

3. DEMONSTRATE VOICE COMMANDS
   - Say "directions" → Hear current directions
   - Say "where am I" → Hear location description
   - Say "zoom in" → Watch map zoom

4. SHOW VISUAL ENHANCEMENTS
   - Enable "High Contrast" mode
   - Enable "Large Text" mode
   - Show before/after comparison

5. KEYBOARD SHORTCUTS
   - Press Alt + A → Toggle panel
   - Press Alt + D → Speak directions
   - Press Alt + L → Describe location
```

### Scenario 3: Accessibility User Journey
**Duration**: 5-7 minutes  
**Purpose**: Show complete user experience for someone with visual impairments

```
1. USER CONTEXT
   "Meet Sarah, who has low vision and relies on 
   audio navigation and high contrast interfaces"

2. STANDALONE APP JOURNEY
   - Sarah opens the app
   - Uses voice: "Hey Assistant, help me navigate"
   - Sets up route with accessible preferences
   - Follows audio directions with detailed descriptions
   - Uses satellite view for visual context

3. GOOGLE MAPS EXTENSION JOURNEY
   - Sarah uses familiar Google Maps
   - Extension enhances with accessibility features
   - Voice commands provide hands-free control
   - High contrast mode improves visibility
   - Audio feedback confirms all actions

4. HIGHLIGHT IMPACT
   - Compare with/without accessibility features
   - Show how technology removes barriers
   - Demonstrate independence and confidence
```

## 🎬 Demo Presentation Tips

### Before the Demo
1. **Test everything** in the exact environment
2. **Prepare backup scenarios** if APIs fail
3. **Have demo data ready** (addresses, commands)
4. **Check audio/video setup** for presentations
5. **Practice timing** to fit available time

### During the Demo
1. **Start with context** - explain the problem
2. **Show before/after** - demonstrate improvement
3. **Use real data** - avoid obviously fake scenarios
4. **Encourage interaction** - let audience try features
5. **Address questions** - be prepared for technical details

### After the Demo
1. **Gather feedback** - what worked, what didn't
2. **Provide next steps** - how to get started
3. **Share resources** - documentation, contact info
4. **Follow up** - continue the conversation
5. **Iterate** - improve based on feedback

## 🚀 Demo Environments

### Local Development
```
PROS: Full control, can modify on the fly
CONS: Requires setup, may have environment issues
BEST FOR: Technical audiences, development teams
```

### Staging/Production
```
PROS: Reliable, real-world performance
CONS: Less flexibility, potential API limits
BEST FOR: Business stakeholders, end users
```

### Recorded Demo
```
PROS: Perfect execution, no technical issues
CONS: Less interactive, can't adapt to questions
BEST FOR: Large presentations, marketing materials
```
