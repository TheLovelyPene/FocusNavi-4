# Accessible Navigation Assistant - Google Maps Extension

A Chrome extension that enhances Google Maps with accessibility features for users with visual impairments and mobility challenges.

## Features

### Voice Commands
- **"Directions"** - Speaks current navigation directions
- **"Where am I"** - Describes current location
- **"Accessible route"** - Finds accessible route options
- **"Zoom in/out"** - Controls map zoom level
- **"Search for [location]"** - Performs location search

### Audio Feedback
- Text-to-speech for all directions and location information
- Automatic announcement of new directions during navigation
- Customizable speech rate and volume

### Visual Accessibility
- High contrast mode for better visibility
- Large text mode for easier reading
- Enhanced focus indicators for keyboard navigation

### Keyboard Shortcuts
- **Alt + A** - Toggle accessibility panel
- **Alt + D** - Speak current directions
- **Alt + L** - Describe current location

### Quick Actions
- One-click access to common accessibility features
- Context menu integration for right-click access
- Floating accessibility panel for easy control

## Installation

### From Chrome Web Store (Recommended)
1. Visit the Chrome Web Store
2. Search for "Accessible Navigation Assistant"
3. Click "Add to Chrome"
4. Navigate to Google Maps to start using the extension

### Manual Installation (Development)
1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the extension folder
5. The extension will be installed and ready to use

## Usage

1. **Navigate to Google Maps** in your Chrome browser
2. **Look for the accessibility panel** in the top-right corner of the page
3. **Enable desired features** using the checkboxes in the panel
4. **Use voice commands** by speaking clearly (if voice recognition is enabled)
5. **Access quick actions** through the extension popup or keyboard shortcuts

## Permissions

The extension requires the following permissions:
- **activeTab** - To interact with Google Maps pages
- **storage** - To save your accessibility preferences
- **geolocation** - To provide location-based features
- **tts** - For text-to-speech functionality

## Privacy

This extension:
- ✅ Only works on Google Maps pages
