# Privacy Policy - Accessible Navigation Assistant

**Last Updated**: [Current Date]

## Overview

Accessible Navigation Assistant ("we", "our", or "the extension") is committed to protecting your privacy. This privacy policy explains how our Chrome extension collects, uses, and protects your information.

## Information We Collect

### Information We DO Collect
- **Extension Settings**: Your accessibility preferences (voice commands on/off, high contrast mode, etc.)
- **Usage Analytics**: Anonymous data about which features are used (no personal identification)

### Information We DO NOT Collect
- ❌ Personal identification information
- ❌ Location data or navigation history
- ❌ Search queries or destinations
- ❌ Voice recordings or transcripts
- ❌ Browsing history outside of Google Maps
- ❌ Any data that could identify you personally

## How We Use Information

### Settings Storage
- Settings are stored locally in your browser using Chrome's storage API
- Settings sync across your Chrome browsers if you're signed in to Chrome
- We never access or transmit your settings to external servers

### Voice Recognition
- Voice commands are processed locally by your browser
- No voice data is recorded, stored, or transmitted
- Voice recognition uses your browser's built-in speech recognition API

### Analytics (Anonymous Only)
- We may collect anonymous usage statistics (e.g., "feature X was used Y times")
- This data cannot be linked to individual users
- Used only to improve the extension and understand feature popularity

## Data Sharing

We do not share, sell, or transmit any user data to third parties. Period.

### What We Don't Do
- ❌ Sell data to advertisers
- ❌ Share data with Google (beyond standard Chrome extension APIs)
- ❌ Transmit data to external servers
- ❌ Use data for marketing purposes
- ❌ Create user profiles or tracking

## Permissions Explained

Our extension requests these permissions:

### `activeTab`
- **Purpose**: To interact with Google Maps pages
- **Scope**: Only active Google Maps tabs
- **Usage**: Add accessibility features to the Google Maps interface

### `storage`
- **Purpose**: Save your accessibility preferences
- **Scope**: Local browser storage only
- **Usage**: Remember your settings between browser sessions

### `tts` (Text-to-Speech)
- **Purpose**: Provide audio feedback for navigation
- **Scope**: Browser's built-in text-to-speech only
- **Usage**: Read directions and location information aloud

### `geolocation` (Optional)
- **Purpose**: Describe your current location when requested
- **Scope**: Only when you explicitly use the "describe location" feature
- **Usage**: Provide context about your current position

## Data Security

### Local Storage Only
- All data is stored locally in your browser
- No data transmission to external servers
- Data is protected by Chrome's security model

### No External Dependencies
- Extension works entirely offline (except for Google Maps itself)
- No third-party tracking scripts
- No external API calls for user data

## Your Rights

### Data Control
- **Access**: View your settings in the extension popup
- **Modify**: Change settings anytime through the extension interface
- **Delete**: Uninstall the extension to remove all data
- **Export**: Settings are standard Chrome storage (can be backed up)

### Opt-Out Options
- Disable any feature through the settings panel
- Turn off voice commands completely
- Disable analytics (if implemented in future versions)
- Uninstall the extension anytime

## Children's Privacy

This extension does not knowingly collect information from children under 13. The extension is designed for general accessibility use and does not target children specifically.
