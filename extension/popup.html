Accessible Navigation

Enhance Google Maps with accessibility features

Extension Active on Google Maps

Features Available

  • Voice commands for hands-free navigation
  • Audio descriptions of directions
  • High contrast and large text modes
  • Keyboard shortcuts for quick access
  • Automatic direction announcements
  • Accessible route finding

Quick Actions

Keyboard Shortcuts

Alt + A: Toggle accessibility panel
Alt + D: Speak current directions
Alt + L: Describe current location
